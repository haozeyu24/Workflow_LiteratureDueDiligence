# Instruction

Identify papers relevant to understanding host-pathogen relationships across multiple viruses, using Krogan lab AP-MS host-virus interaction data and related literature as the starting context.

Prioritize papers that help identify host-pathogen mechanisms shared across multiple viruses, especially cases where different viruses do not target the same human protein directly but instead converge on a shared host pathway, process, complex, or cellular program.

The workflow should:

1. generate a PubMed search strategy from this objective
2. collect title, abstract, and metadata
3. review abstract-level relevance to the objective
4. acquire and normalize full text
5. decide which papers belong in the final reading set

Favor mechanistic and pathway-informative papers over broad descriptive or tool-only papers.
