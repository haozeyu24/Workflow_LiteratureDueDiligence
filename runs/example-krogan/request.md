# Request

Krogan lab has AP-MS data between different viruses and human, including KSHV, Dengue, Hepatitis C, Coxsackie, HIV, and Ebola.

The goal is to explore these data, together with related literature, to understand host-pathogen relationships.

The scientific focus is on identifying host-pathogen mechanisms that are shared across multiple viruses, especially difficult cases where the viruses do not target the same human protein directly but instead converge on a host pathway, process, complex, or cellular program.
