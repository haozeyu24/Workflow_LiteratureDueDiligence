# Topic

Krogan lab has AP-MS host-virus interaction data across multiple viruses, including:

- KSHV
- Dengue
- Hepatitis C
- Coxsackie
- HIV
- Ebola

The scientific objective is to explore those data together with the literature to better understand host-pathogen relationships, with emphasis on:

- host-pathogen mechanisms shared across multiple viruses
- pathway-level convergence across viruses
- difficult cases where different viruses do not hit the same host protein but still appear to perturb the same host pathway or biological process

This topic should be treated as a mechanism-discovery and evidence-integration problem, not just a paper collection exercise.
