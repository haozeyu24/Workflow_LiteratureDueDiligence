# Request

Build a literature pool to support a short-term staff-scientist project on community-of-agents discovery of shared host-pathogen mechanisms across multiple viruses. The immediate data context is Krogan-lab-style AP-MS virus-human interaction data for KSHV, dengue virus, hepatitis C virus, coxsackievirus, HIV, and Ebola virus.

The pool should prioritize studies that connect these viruses to host-pathogen protein interactions, interactome/proteomics/AP-MS datasets, and mechanistic host pathway perturbations. The motivating biological problem is to identify shared host pathways across viruses, including challenging cases where different viral proteins do not target the same human protein but converge on a host pathway or complex.
