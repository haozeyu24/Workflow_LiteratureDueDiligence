# Review Frame

This file is a run-specific input, not part of the reusable workflow spec.

Use it to capture review-article obligations that should influence retention and
later synthesis more strongly than first-pass retrieval.

Keep this file distinct from `instruction.md`:

- `instruction.md` defines the primary retrieval contract
- `review_frame.md` defines how the final review should be situated in the
  larger field

Only promote `review_frame.md` items into PubMed query drivers when they name
explicit foundational terms, parent-field aliases, or comparator concepts that
the run explicitly wants preserved for recall.

## Retention guidance

Papers may be retained partly because they serve one of these review roles:

- `direct_mechanistic`
- `clinical_translational`
- `foundational_background`
- `field_synthesis`
- `perspective_gap`

Use these roles to justify a minority of context-setting papers without letting
them overtake the direct-mechanism corpus.
