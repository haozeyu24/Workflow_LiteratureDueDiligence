# Topic Template

This file is a run-specific input, not part of the reusable workflow spec.

For each run, write a scoped topic framing here.

The topic may include:

- pathogens or viruses of interest
- host systems or pathways of interest
- relevant assays or datasets
- explicit scope boundaries
- special biological nuance the reviewers should keep in mind

This file should be generated or drafted by the `runSetupAgent` role from the user request.

## Reuse rule

This file may contain detailed biological specifics for a run.

Reusable workflow components must treat it as data, not as hardcoded logic.
